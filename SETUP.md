# Setup

1. Copy all files into the profile repository named `Focaccina-Ripiena37`.
2. Commit and push them to the default branch.
3. Open **Actions → Update profile visuals → Run workflow** once.
4. The workflow refreshes the SVG assets every day.
5. Edit `.github/scripts/generate_profile.py` to change wording, colors, or project selection.

No GitSkins endpoint is required: the README loads SVG files directly from your own repository.
